Project Title: Go Cab - Real-Time Cab Booking & Driver Platform
Live Deployed Website URL: https://n1rnjn.github.io/go-cab/

Key Features:
- Passenger Cab Booking with distance & live fare calculator
- Interactive Leaflet.js live driver tracking map with polylines
- Dedicated Driver Partner Portal (driver.html) with Online/Offline switcher
- Ride security 4-digit OTP verification (OTP: 7492)
- Driver daily earnings meter & bank cashout system
- Red Bull High-Energy theme design system

Tech Stack: HTML5, Vanilla CSS3 (Custom properties & dark theme tokens), ES6+ JavaScript, Leaflet.js CartoDB tiles.
